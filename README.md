# English Tutor · 수능 영어 자료실

수능 영어 자료 업로드, 검색, 유형·학년별 필터, 정렬, 원본 다운로드를 지원합니다. 등록된 자료와 파일은 서버의 `data/` 폴더에 보관되어 재시작 후에도 유지됩니다. 예시 자료 없이 빈 자료실로 시작합니다.

## 실행

Node.js 22에서 이 폴더를 터미널로 열고 실행하세요.

```sh
npm install
npm start
```

브라우저에서 http://127.0.0.1:3000 에 접속합니다. `PORT` 환경변수로 포트를 바꿀 수 있습니다.

## 파일

- PDF, HWP, HWPX, DOCX, XLSX, PPTX, TXT, ZIP, MP3를 지원합니다. 파일당 최대 25MB입니다.
- 백업 시 `data/` 전체를 복사하세요. 서버를 여러 개 동시에 실행하는 구성은 지원하지 않습니다.
- 자료 등록·관리·삭제는 관리자 키 인증을 사용합니다. 기본 로컬 주소는 이 컴퓨터에서만 접근 가능합니다. 공개 운영에는 아래 운영자·개인정보 설정이 필요합니다.
- 본인에게 공유 권한이 있는 자료를 등록하세요.

## Vercel 배포

저장소 루트의 `vercel.json`이 정적 페이지와 Node.js API를 각각 배포합니다. 홈페이지 표시에는 저장소 연결이 필요하지 않습니다. 파일을 업로드하려면 다음 설정이 필요합니다.

1. Vercel의 englishtutor 프로젝트에서 Storage → Create Database → Blob을 선택합니다.
2. **Private** 저장소를 만들고 프로젝트의 Production 환경에 연결합니다.
3. `BLOB_READ_WRITE_TOKEN` 환경변수가 연결되었는지 확인합니다. 토큰은 소스 코드에 넣지 마세요.
4. Deployments에서 최신 배포를 Redeploy합니다.

Vercel에서는 자료 원본과 자료 정보가 Blob에 저장되어 재배포 후에도 유지됩니다. 저장소가 없으면 자료실 화면은 열리고 업로드 준비 중 안내가 표시됩니다. Vercel의 요청 본문 크기 제한에 맞춰 파일당 최대 3MB를 지원합니다. 로컬 서버는 기존 25MB 제한을 유지합니다.

배포 확인: 홈페이지, `/api/config`, `/api/materials`가 응답하는지 확인하고, 작은 TXT 파일을 올려 다운로드를 검증하세요. 자료 등록과 삭제에는 관리자 인증이 필요합니다.


## 운영 전 필수 설정

Vercel Project Settings → Environment Variables에 실제 값을 넣고 Redeploy하세요. 서버에만 설정하며 소스에 비밀키를 커밋하지 않습니다.

| 환경변수 | 설정 내용 |
| --- | --- |
| `ADMIN_TOKEN` | 암호학적 난수로 만든 32자 이상 관리자 키. 브라우저에서는 메모리에만 사용하며 사용 후 로그아웃하세요. |
| `OPERATOR_NAME` | 실제 운영자/운영 주체 및 저작권 요청 수령인 |
| `CONTACT_EMAIL` | 실제 수신·회신할 수 있는 문의/권리신고 이메일 |
| `PRIVACY_OFFICER` | 실제 개인정보 보호 담당자 |
| `PRIVACY_INFRA_DETAILS` | 실제 호스팅/저장 위탁·국외 처리 내역. 사업자·연락처, 항목, 목적, 근거, 국가, 시기·방법, 보유기간, 거부 절차·효과를 확인해 입력 |
| `PRIVACY_INQUIRY_DETAILS` | 이메일 문의·신고 항목·목적·적법한 처리 근거·보유기간·파기 방법·이메일 수탁자/국외 처리 내역 |
| `BLOB_READ_WRITE_TOKEN` | Vercel Private Blob 연결 시 제공되는 서버 전용 토큰 |

설정 누락 시 신규 등록 및 자료 공개·다운로드를 차단합니다. 홈페이지와 법적 안내는 열립니다. 설정만 채우면 적법성을 보장하는 것은 아니며, 실제 운영과 안내가 일치해야 합니다. 호스팅 접속 로그는 준비 상태에서도 발생할 수 있습니다.

## 관리자 운영 절차

- “관리자 자료 등록”에서 키를 입력해 등록하거나 “등록 자료 관리”로 기존 자료를 조회·삭제합니다. 기존 미확인 자료도 설정 완료 전 조회·삭제할 수 있습니다.
- 자료 전체의 공개·복제·전송 권한과 제3자 지문·음원·이미지 권리를 확인하고 출처, 권리자 표시, 허락 범위, 권리 근거를 작성합니다. 서버도 확인 항목을 검사합니다. 증빙 내용은 공개 목록에서 제외합니다.
- 기존 자료는 이번 정책 버전의 권리 확인 기록이 없으면 자동 비공개 처리합니다. 삭제하고 권리를 확인하여 다시 등록하세요. 기존 파일은 자동 삭제하지 않습니다.
- 제3자 개인정보가 있는 파일은 등록하지 마세요. 검토는 사람의 책임이며 자동 개인정보 탐지·백신 검사는 구현되어 있지 않습니다.
- 권리신고 링크는 이메일 앱을 여는 기능입니다. 신고는 전송 후 운영자가 수신·검토하며, 적법한 중단 요구에 대한 즉시 조치·통보와 재개 절차를 실제로 수행해야 합니다. 단순 면책 문구로 의무를 대신할 수 없습니다.
- 삭제는 저장 원본과 자료 정보 제거를 시도하고 실패하면 오류를 반환합니다. Vercel의 백업·로그·외부 메일과 이미 내려받은 사본은 별도 범위이므로 실제 삭제/보존 정책을 관리하세요.
- 운영 중에 키가 노출되면 즉시 환경변수에서 교체하고 재배포하세요. 인터넷 공개 환경은 Vercel Firewall에서 요청 제한도 설정하세요.
